# API Brand Alignment

The public `api.terrasatch.com` root is intentionally aligned with the current TerraSatch public website rather than presented as a separate visual identity.

## Shared brand cues

- TerraSatch illustrated badge/logo
- near-black field-operations palette with warm orange/gold accents
- cream/white primary typography
- `WASATCH FRONT · UTAH` geographic framing
- `TERRAIN INTELLIGENCE` hero language
- AI-powered / field-grade / decision-support positioning
- coordinates / elevation / UTM instrument-style metadata
- modular architecture cards and numbered system stages
- restrained terrain/pine geometry used as a supporting accent rather than the primary logo

## API-specific purpose

The API host remains a lightweight developer/operator portal. It surfaces:

- readiness / health
- Swagger when enabled
- OpenAPI
- admin console
- current deployment metadata
- control-plane and TerraListen radio-intelligence architecture

The API landing page should remain visually related to `terrasatch.com` while avoiding the weight and complexity of the full public marketing site.
